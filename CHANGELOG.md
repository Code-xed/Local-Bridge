# Changelog

## 0.2.0-alpha
- Added Android folder picker for the shared directory, with persisted URI permissions.
- Preserved the existing app-specific Shared folder as the default when no custom folder is chosen.
- Added a configurable HTTP file path (default `/files`).
- Added custom static website directory hosting from `/`, including relative CSS, JavaScript, image and asset paths.
- Kept the built-in LocalBridge page as the default when no custom website is selected.
- Added basic nested-folder browsing and uploads/downloads within existing shared subfolders.
- Kept the same LocalBridge identity and existing GitHub Actions build flow.
